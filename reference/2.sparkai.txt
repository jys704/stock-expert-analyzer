미지는 보통 이렇게 단순화하는 게 좋습니다. 캔들 + 20/60/120 이평선 + 거래량 + RSI
정도까지만 넣고, 배경색/보조지표/텍스트 라벨은 최소화하는 방식입니다. mplfinance는 이
동평균과 거래량, 파일 저장 흐름을 이미 지원하므로 이런 목적에 잘 맞습니다. Source

prompt = """

이 훨씬 좋아집니다. Source

5. Python 자동화는 “이미지 분석”보다 “수치 선계
산”을 먼저 하는 편이 더 낫습니다
실무적으로는 AI가 차트 전체를 처음부터 다 해석하게 하는 것보다, Python이 먼저 수치를
계산한 뒤 AI는 최종 판독자 역할만 하게 하는 게 좋습니다. 예를 들면 20/60/120 이동평
균, 52주 신고가 근접도, 최근 20일 최고가 돌파 여부, RSI, 거래량 평균 대비 비율은
Python/Pandas에서 먼저 계산하고, Gemini에는 “수치 + 차트 이미지”를 같이 주는 방식입
니다.
이 구조의 장점은 분명합니다. 첫째, AI 환각이 줄어듭니다. 둘째, 조건 검색 속도가 빨라집
니다. 셋째, 나중에 백테스트할 때 판정 근거를 분리할 수 있습니다. 즉 정량 규칙은 코드,
애매한 패턴 해석은 비전 AI로 역할을 나누는 게 가장 현실적입니다.

6. Google Sheets IMAGE 함수는 편하지만, 운영
안정성은 제한적입니다
IMAGE(url)은 셀 안에 외부 이미지를 넣는 데 적합합니다. 다만 공식 도움말 기준으로

drive.google.com URL은 직접 사용할 수 없고, SVG는 지원되지 않으며, URL은 프로토콜
을 포함한 직접 접근 가능한 주소여야 합니다. Source
그래서 “네이버 증권에서 차트 이미지 주소 복사 → =IMAGE()” 방식은 간편한 모니터링용
으로는 괜찮지만, 장기 운영용으로는 불안정할 수 있습니다. 이유는 외부 사이트의 URL 구
조 변경, 핫링크 차단, 캐시 반영 지연, 이미지 응답 정책 변경 때문입니다. 공식 문서가
“자동 갱신 보장”을 약속하는 것은 아니고, 단지 외부 URL 이미지를 셀에 삽입하는 기능을
설명합니다. 즉, 가능은 하지만 SLA가 없는 방식으로 이해하는 게 맞습니다. Source

7. 시트 쪽은 오히려 GOOGLEFINANCE와 결과 테
이블을 같이 쓰는 편이 더 좋습니다
Google Sheets에는 GOOGLEFINANCE() 함수가 있어서 가격, 거래량, 고가/저가, 시가총액,
52주 고저 등 일부 지표를 바로 불러올 수 있습니다. 다만 문서상으로 실시간 데이터는 최
대 20분 지연될 수 있고, 국제 거래소 지원이 제한적이며, 역사 데이터는 Apps Script나
Sheets API로 직접 접근할 수 없는 제약도 있습니다. Source
그래서 추천 구조는 이렇습니다.
차트 이미지는 IMAGE()로 “보조 시각화”만 쓰고, 핵심 판단값은 Python이 만든 CSV/시트
테이블에 넣는 방식입니다. 예를 들어 시트 컬럼을 종목코드 / 종목명 / 종가 / 20MA /
60MA / 정배열 / 돌파 / 거래량급증 / AI의견 / 신뢰도 / 차트이미지 식으로 구성하면, 필
터링과 정렬은 수치 컬럼으로 하고 이미지는 사람이 최종 확인할 때만 보는 구조가 됩니다.

8. 지금 가이드를 “운영형 설계”로 바꾸면 이런 구
조가 가장 깔끔합니다
추천 아키텍처는 아래 순서입니다.
1. yfinance로 종목별 OHLCV 수집
2. Pandas로 이동평균, RSI, 거래량 배수, 신고가 근접도 계산
3. 1차 규칙 필터로 종목 수를 줄임
4. 살아남은 종목만 mplfinance로 차트 저장
5. Gemini에 차트 이미지 + 계산된 수치 요약 전달
6. JSON 결과를 DataFrame으로 적재
7. CSV 저장 또는 Google Sheets 업로드
8. 시트에서 필터/조건부서식/대시보드 운영
이렇게 하면 AI 호출 비용도 줄고, 수백 개 종목을 매일 돌려도 실용성이 생깁니다. 사용자
가이드 마지막 문장처럼 “AI가 선별한 유망 종목만 집중 검토”하는 흐름이 실제로 구현됩니

def calc_indicators(df):
df = df.copy()
df["ma20"] = df["Close"].rolling(20).mean()
df["ma60"] = df["Close"].rolling(60).mean()
df["ma120"] = df["Close"].rolling(120).mean()
delta = df["Close"].diff()
up = delta.clip(lower=0).rolling(14).mean()
down = (-delta.clip(upper=0)).rolling(14).mean()
rs = up / down
df["rsi14"] = 100 - (100 / (1 + rs))
df["vol20"] = df["Volume"].rolling(20).mean()
return df

def analyze_chart_with_gemini(image_path, summary_text):
with open(image_path, "rb") as f:
image_bytes = f.read()
prompt = f"""
너는 한국어 기술적 분석 보조 엔진이다.
아래 차트 이미지와 수치 요약을 참고해 JSON만 출력하라.

{summary_text}
JSON schema:
{{
"uptrend_alignment": true,
"breakout": false,
"volume_surge": false,
"rsi_state": "neutral",
"action": "buy_watch",
"confidence": 73,
"comment": "20·60·120일선 정배열 유지, 돌파 확인은 추가 필요"
}}
"""
response = client.models.generate_content(
model="gemini-2.5-flash",
contents=[

)

return json.loads(response.text)
