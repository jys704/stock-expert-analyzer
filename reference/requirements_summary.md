# 첨부자료 기반 요구사항 요약

사용자는 첨부된 AI 질의·응답, 기존 Python 분석 코드, 기존 출력 차트, 그리고 유튜브 요약 PDF의 내용을 바탕으로 **주식 투자 전문가가 참고 리포트를 작성하듯 종목을 분석하는 웹앱**을 원한다. 이 앱은 사용자가 사고자 하는 종목을 입력하면 기술적 지표와 테마·거래대금 관점의 체크리스트를 제공하며, 투자 판단 자체를 대신하기보다 참고용 분석 자료를 생성하는 방향으로 설계한다.

| 구분 | 반영할 내용 | 앱 구현 방향 |
|---|---|---|
| 기존 Python 코드 | yfinance 기반 가격 데이터, MA20/60/120, RSI14, 거래량 20일 평균, 20일·60일 고점 돌파, 거래량 급증 판정, 차트 이미지 생성, Gemini JSON 분석 프롬프트 | 브라우저에서 사용 가능한 샘플 데이터·수동 입력 기반 분석 로직으로 우선 구현하고, 추후 개인 계정에서 API 키를 연결하면 실시간 데이터/AI 분석으로 확장 가능한 구조로 문서화한다. |
| output.zip | AAPL, MSFT, NVDA 차트 이미지와 API 키 오류 기록 | 기존 출력물은 UI 참고 자료로 활용하되, API 키는 프로젝트에 포함하지 않는다. 오류 원인은 유효하지 않은 Gemini API 키로 기록되어 있으므로 개인 계정 이전 시 환경변수 설정 항목으로 분리한다. |
| 유튜브 요약 PDF | 급등주 쉐도잉, 거래대금 500억 이상 종목 관찰, 키워드 캘린더, 키워드 백과사전 | 앱에 ‘전문가 체크리스트’, ‘키워드/테마 메모’, ‘거래대금·등락률 기반 관심도 점수’, ‘리스크 코멘트’를 포함한다. |
| 접근 제한 | 몇몇 사람만 볼 수 있게 비밀번호 로그인 | 정적 Firebase Hosting에서 동작 가능한 클라이언트 비밀번호 보호를 우선 구현한다. 더 강한 보안은 추후 Firebase Authentication 또는 백엔드 연동으로 확장한다. |
| 독립 사용 | 중앙 공유 서비스가 아니라 각 사용자가 자기 환경에서 복사·수정·배포 | 현재는 독립형 소스와 문서만 완성한다. 저장소 URL, Firebase 프로젝트 ID, API 키, 비밀번호는 하드코딩하지 않고 `.env.example`, `firebase.json`, README 절차로 분리한다. |

> 설계 원칙은 “한 곳에서 사용자들을 관리하는 서비스가 아니라, 완성된 앱 패키지를 각자가 자기 계정과 자기 환경에서 가져가 사용하는 것”이다. 따라서 실제 GitHub 원격 저장소 생성, Firebase 로그인, Firebase 프로젝트 선택, 배포 명령 실행은 각 사용자 환경에서 수행하도록 안내한다.
