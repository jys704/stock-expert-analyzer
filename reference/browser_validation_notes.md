# 브라우저 검증 기록

로그인 화면은 정상적으로 표시되었고, 데모 비밀번호 `stock2026` 입력 후 주식 분석 대시보드로 진입하는 것을 확인했다. 초기 해시 값이 잘못되어 로그인 실패가 발생했으나, 실제 SHA-256 값 `1aeaf73d994452190c20e0e76fd0648137a402055f18326eef825b5e034fa362`로 수정한 뒤 정상 로그인되었다.

대시보드는 비밀번호 보호 배지, 독립형 배포 패키지 안내, 현재 분석 등급 A/84점, 종목 입력 패널, 전문가형 요약 리포트, 차트, 거래량·RSI·거래대금 지표를 표시한다. NVDA 샘플 데이터가 기본값으로 로드되며, AAPL/MSFT 버튼을 통해 예시 데이터를 바꿀 수 있는 상태다.
